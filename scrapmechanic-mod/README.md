# scrapmechanic-mod

Scrap Mechanic survival mod. Lua + JSON data mod using the
game's built-in mod system.

## Game

- **Game:** Scrap Mechanic
- **Engine:** custom (C++ core, Lua 5.1 scripting, JSON data)
- **Mod system:** built-in (workshop or local `Survival/` override)
- **Language:** Lua, JSON
